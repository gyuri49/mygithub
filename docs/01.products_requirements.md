# 상품 목록 페이지 요구사항 분석 및 기능 목록

## 📌 기본 정보
### 프로젝트명:
신발 쇼핑몰 상품 목록 페이지

### 사용하게 될 기술: 
React

### 문서 작성자: 
만다린

## 📝 고객 요구사항 정리
- 웹페이지와 모바일 환경에서도 사용할 수 있는 화면 구성
- 상품 사진이 잘 보이도록 하기
- 화면 상단 오른쪽 장바구니 표시, 상품 추가시 실시간으로 증가하는 상품 개수 표시
- 테스트 url 배포

## 📋 기능 목록
- 웹 페이지 / 모바일 화면
- 이미지가 포함된 상품 리스트 // 상품을 2개의 컬럼으로 보여주기
- '담기' 버튼과 담김 상태 변화(버튼의 색을 다르게 하여 표시)
- 장바구니에 담긴 수
- 무한 스크롤
