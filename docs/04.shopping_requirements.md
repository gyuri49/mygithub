# 쇼핑몰 연동 요구사항 분석 및 기능 목록

## 📌 기본 정보
### 프로젝트명: 
 패션 쇼핑몰 연동 

### 사용하게 될 기술: 
 React

### 문서 작성자: 
 만다린

## 📝 고객 요구사항 정리
1. 페이지 연동
   - 상품 목록, 장바구니, 결제 등 모든 페이지에서 자연스러운 이동
2. 데이터 일관성
   - 페이지 간 이동이 있어도 데이터 일관되게 유지
3. 상세 페이지 추가
   - 상품을 클릭했을 때 상세 페이지 등장, 상품에 대한 상세 정보와 관련 상품 보여주기
4. 테스트 url 제공

## 📋 기능 목록
-상세페이지 제작
-결제 완료 페이지
