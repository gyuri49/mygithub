# 장바구니 페이지 리뷰

## 고객사 요구사항
1. 상품의 가격, 수량에 따른 총 금액, 배송비를 볼 수 있게 해주세요.
2. 상품 10만원 이상 구매 시 배송비는 무료로 적용되게 해주세요.
3. 뒤로가기 버튼을 누르면 상품 목록 페이지로 이동할 수 있도록 해주세요.
4. 결제하기 버튼을 누르면 결제 모듈을 사용할 수 있도록 해주새요.

## 요구사항에 따른 기능 동작 확인

1. 뒤로가기 버튼
   뒤로가기 버튼을 누르면 상품 목록 페이지로 이동해야 합니다.
2. 결제하기 버튼
   결제하기 버튼을 누르면 결제 모듈이 나타나야 합니다.
3. 장파구니 페이지
   상품명, 가격, 수량이 표시됩니다. 총 금액과 배송비가 표시됩니다. (10만원 이상 구매 시 무료배송)
