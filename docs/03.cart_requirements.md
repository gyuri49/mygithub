# 장바구니 페이지 요구사항 분석 및 기능 목록

## 📌 기본 정보
### 프로젝트명: 
패션 쇼핑몰 장바구니 페이지

### 사용하게 될 기술: 
React

### 문서 작성자: 
만다린

## 📝 고객 요구사항 정리
- 담긴 상품의 목록 표시
  = 상품 이름, 상품 가격, 수량 표시
- 담긴 상품의 총 금액, 배송비 3000원 표시
  = 10만원 이상 구매시 배송비 무료
- 뒤로가기 버튼을 누르면 메인 상품 목록 페이지로 이동
- 결제하기 버튼을 누르면, 결제 모듈을 모달로 사용할 수 있게 연동
- test url 제공

## 📋 기능 목록
- 뒤로 가기 버튼
- 버튼을 통해 상품의 수량 조절
- 결제하기 버튼을 통한 결제
- 추가적인 요소로, 굳이 상품을 장바구니에서 삭제시키지 않아도 체크를 통해 특정 상품만 결제할 수 있는 기능도 추가(확정되지 않음)
