# 결제 모듈 요구사항 분석 및 기능 목록

## 📌 기본 정보
### 프로젝트명: 
쇼핑몰 결제 모듈 구축

### 사용하게 될 기술: 
React

### 문서 작성자: 
만다린

## 📝 고객 요구사항 정리
1. 여러 개의 카드 등록 가능
2. 신용카드 등록 가능
3. 민감한 정보가 노출되지 않도록 보안 철저하게 하기
4. 상품 목록 '담기'버튼 옆에 '결제' 버튼 추가하기
5. Test Url 요

## 📋 기능 목록
- 상품 목록 '담기' 버튼 옆에 '결제' 버튼 추가
- 카드 목록
- 카드 추가
 - 카드 번호, 만료일, 소유자명, 보안 코드, 카드 비밀 번호
   * 카드 번호: 숫자만 입력, 4글자씩 끊기, 뒤에 8자리 숨김 처
   * 만료일: 숫자만 입력, MM/YY 형식
   * 소유자명: '카드에 표시된 이름과 동일하게 입력하세요.'
   * 보안 코드: 숨김 처리
   * 카드 비밀번호: 앞의 2자리만 입력, 숨김처리
