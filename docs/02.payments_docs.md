# 결제 모듈 프로젝트

## 프로젝트 개요

- 이 결제 모듈은 카드를 등록하고 결제할 수 있게 도와주는 모달 컴포넌트입니다.
- 만다린

## 개발 환경

React, JavaScript


## 설치 및 실행 방법


npm install
npm start


## 컴포넌트 구조

- CardList: 등록된 카드를 표시합니다.
- CardNumberInput: 카드 번호를 입력하는 Input 컴포넌트입니다. 숫자만 입력할 수 있도록 코딩했습니다.
- CardPasswordInput: 카드 비밀번호 앞의 2자리만 입력하도록 하는 input 컴포넌트입니다. 비밀번호는 숨김처리됩니다.
- CVCInput: 보안코드를 입력하도록 합니다. 번호는 숨김처리됩니다.
- ExpiryDateInput: 만료일을 입력하는 Input 컴포넌트 입니다. MM/YY 양식으로 작성할 수 있습니다.
- OwnerName: 소유자명을 입력하는 input 컴포넌트입니다.
- NewCardPage: 새로운 카드를 등록하는 페이지입니다.
