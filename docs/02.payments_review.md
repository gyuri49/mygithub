# 결제 모듈 리뷰

## 고객사 요구사항
1. 신용카드 등록 기능을 넣어주세요.
2. 보안을 철저하게 해주세요.
3. 사용자가 여러 개의 카드를 등록하게 해주세요.
4. 카드 비밀번호, 보안 코드 등 중요 정보는 숨김 처리 해주세요.
5. 상품 목록에서 담기 버튼 바로 옆에 '결제' 버튼을 추가세주세요.

## 요구사항에 따른 기능 동작 확인

1. 카드 등록 기능
  보유 카드 목록에서 카드 추가를 눌러 새로운 카드를 추가할 수 있습니다.


2. 카드 번호 입력
  카드 번호는 16자리 '숫자'로만 입력할 수 있고, '-' 기호로 4자리씩 자동으로 끊어줄 수 있습니다.


4. 상품 카드의 결제 버튼
  담기 버튼 오른쪽에 결제 버튼을 넣습니다.


5. 보안 코드, 카드 비밀번호 숨김 기능
   보안 코드와 비밀 번호는 숨김 처리하여 보안을 철저히 합니다.
