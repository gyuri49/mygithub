# 장바구니 프로젝트

## 프로젝트 개요

- 장바구니 페이지는 담음 상품의 목록 및 개수, 배송비를 포함한 상품의 총 가격을 확인하는 기능을 제공합니다.
- 참여한 팀원: 만다린

## 개발 환경

React, JavaScript

## 설치 및 실행 방법


npm install
npm start


## 컴포넌트 구조

BackButton: 뒤로가기 버튼입니다. 장바구니 이전 페이지로 이동할 수 있습니다.
PayButton: 결젷기 버튼입니다.
Cartlist: 담은 상품의 목록을 보여주고, 수량에 따른 총 금액과 배송비를 표시하는 장바구니 페이지입니다.
